# Action 8 — Rapport et validation utilisateur

> Fait partie du protocole en 8 actions (section 3 de `../../INIT_ETAPES.md`), à
> appliquer identiquement pour chaque étape de `../MAIN.md`. Ce fichier documente le
> protocole lui-même, pas une instance pour une étape donnée.

## Description

Faire un rapport de l'étape à l'utilisateur (ce qui a été fait, décisions prises, état des tests), puis demander l'autorisation explicite avant de démarrer l'étape suivante.

## Notes

Ne jamais enchaîner deux étapes sans validation explicite de l'utilisateur, même si le travail semble évident ou rapide.
