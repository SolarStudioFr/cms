# Action 3 — Commenter le code en anglais

> Fait partie du protocole en 8 actions (section 3 de `../../INIT_ETAPES.md`), à
> appliquer identiquement pour chaque étape de `../MAIN.md`. Ce fichier documente le
> protocole lui-même, pas une instance pour une étape donnée.

## Description

Deux niveaux de commentaires attendus, en anglais, sur chaque fichier/classe modifié pendant l'étape :
1. Un commentaire principal décrivant le rôle du fichier/de la classe.
2. Un commentaire par fonction/méthode, avec `@param`, `@return`, et une description de l'action effectuée.

## Notes

S'applique aux fichiers PHP comme JS/JSX créés ou modifiés pendant l'étape.
