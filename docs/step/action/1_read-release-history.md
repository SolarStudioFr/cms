# Action 1 — Lire l'historique des releases

> Fait partie du protocole en 8 actions (section 3 de `../../INIT_ETAPES.md`), à
> appliquer identiquement pour chaque étape de `../MAIN.md`. Ce fichier documente le
> protocole lui-même, pas une instance pour une étape donnée.

## Description

Avant de commencer le travail d'une étape, lire intégralement `docs/RELEASE.md` pour prendre connaissance de l'historique et du contexte déjà accumulé (versions précédentes, erreurs rencontrées, décisions d'architecture prises pendant les étapes précédentes).

## Notes

`docs/RELEASE.md` n'existe pas encore : il sera créé lors de l'action 6 (« Journaliser ») de la toute première étape démarrée. Chemin interprété comme relatif au dossier `docs/` (même dossier que `INIT_ETAPES.md`), pas relatif à `docs/step/`.
