# Formulaire pour les pages, actualité et réalisation

## Pour tous les formulaires :

- Slug, auto généré a partir du titre
- S.E.O. et réseaux sociaux :
    - Titre S.E.O.
    - Meta description
    - Image OG (modal d'upload)
    - Type OG (liste : website, article, product, profile)
    - URL canonique
- Publication (liste : brouiilon, publié, archivé)
- Image à la une

## Ordre d'affichage :

### Gauche :

- Card -- identité :
    - Titre
    - Slug
- Card -- Contenue :
    - Page builder
- Card -- S.E.O. & réseaux sociaux

### Droite :

- Publication
- Image à la une

## Spécification -- Réalisation :

### Droite :

- Tags (à sélectionné)
- Nouveau tag

## Spécification -- Article :

### Droite :

- Catégorie (liste)
- Nouvelle catégorie
