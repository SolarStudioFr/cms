# Nouveau block pour page builder

## Héro

### Description :

Ajoute un héro sur le site.

### Form :

- Eyebrow (Texte au dessus du titre)
- Titre principal (h1)
- Texte d'accroche (lead)
- Bouton principal -- texte
- bouton principal -- URL
- Bouton secondaire -- texte
- bouton secondaire -- URL

## Ils nous font confience

### Description :

Ajoute une liste de client.

### Form :

- Texte d'introduction
- Clients / logos texte
- Bouton -- Ajouter un client

## Grille des services :

### Description :

Affiche les services proposer par l'entreprise.

### Form :

- Eyebrow
- Titre de section
- Texte d'introduction (lead)

- Liste des services :
    - Bouton -- Ajouter un service
        - Icône (avec recherche)
        - Titre
        - Description

## Notre approche :

### Description :

Liste les méthodes / étapes de notre travail.

### Form :

- Eyebrow
- Titre

- Etapes (4x card) :
    - Libellé numéro
    - Titre
    - Description

## Réalisations (dynamique) :

### Description :

Affiche dynamiquement les dernières réalisations.

### Form :

- Eyebrow
- Titre de la section
- Nombre à afficher
- Texte du lien "Tout voir"
- FDond de section (liste Blanc ou gris doux)

## Actualités (Dynamique)

### Description :

Affiche dynamiquement les dernières actialités.

### Form :

- Eyebrow
- Titre de section
- Nombre à afficher
- Texte lien "Tous voir"
- Fond de section (Blanc ou Gris doux)

## Titre

### Description :

Affiche un titre avec sélection du H1~6.

### Form :

- Bouton de sélection du titre de H1 à H6.
- Texte du titre

## Bouton :

### Description :

Ajouche un bouton.

### Form :

- Texte du bouton
- URL
- Couleur (Liste : primary, secondary, success, warning, danger, info, light, dark)
- Taille (liste : petit, moyen, grand)
- Aouverture (liste : même onglet, nouvel onglet)

## Service (Carte seule)

### Description :

Comme pour "Grille des service" mais avec une seulle carte.

### Form :

- Couleur (liste : primary, secondary, success, warning, danger, info, light, dark)
- Icône (Recherche et liste)
- Titre
- Description

## Tarifs :

### Description :

Affiche trois card de tarif sur le site.

### Form (3x card) :

- Titre
- Tarif
- Icône (recherche et liste)
- Description
- Option incluse :
    - Bouton : Ajouter une option
        - Texte + bouton de suppression de l'option

## Articles / Réalisation (deux bloks) :

### Description :

Affiche les dernieres actualités / réalisations mais sans titre ni description, juste une liste.

### Form :

- Nombre d'article / réalisation
- Ordre : Plus récent / encien en premier (liste, deux choix)
- Articles :
    - Catégories (liste, optionnel)
- Réalisation :
    - Tags (checkbox, optionnel)
